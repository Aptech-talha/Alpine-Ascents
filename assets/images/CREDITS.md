# Image credits

All photographs in `assets/images/` were downloaded from [Unsplash](https://unsplash.com) and
are stored locally as WebP so the site does not depend on a remote image CDN at runtime.

**License:** the [Unsplash License](https://unsplash.com/license) grants free commercial and
non-commercial use, modification, and redistribution without requiring permission. Attribution is
not required, but the source of every file is listed below as good practice.

**Processing:** each file was requested from the Unsplash image CDN with `fm=webp&q=72` at a
maximum width of 1920 px (hero), 900 px (cards, gallery) or 800 px (equipment), which keeps the
whole image set small while remaining sharp on 2x displays. The SVG placeholders in
`assets/images/ui/` were drawn for this project (MIT, same as the project).
